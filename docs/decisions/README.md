# Decision records

**How decisions are logged.** Each decision originates in a maintainer prompt. The agent generates the record: it opens with the verbatim excerpt of the prompt that produced the decision, then states the context, the decision and its consequences. New records start from [`0000-template.md`](0000-template.md).
