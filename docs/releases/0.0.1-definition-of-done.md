# 0.0.1 definition of done

- **Status:** Split by decision 0018: v0 certifies criteria 1 to 3 on the phones; the rest move to 0.0.2

## Scope

v0 runs on two phones: the maintainer's iPhone (iOS 18) and Sabrina's iPhone (iOS 27), installed through TestFlight internal testing. v1 is the App Store release.

## Dev fencing

Every criterion is certified inside the development boundary before any deploy step. The development boundary is CI, the CloudKit Development environment and a TestFlight build on the maintainer's phone holding invented test data. Deploy steps are the CloudKit schema deploy to Production, the production build and adding Sabrina as a tester; each is on the ask-first list in `AGENTS.md`.

## Criteria

| # | Criterion | Certified by |
|---|---|---|
| 1 | Sabrina adds an item from the Share sheet; title, link, store and price fill in or are edited by hand | UI test plus a maintainer run on device |
| 2 | The maintainer sees the shared list, marks items bought and wrapped, and records prices; Sabrina's phone shows none of it | Overlay tests plus a two-account run in the Development environment |
| 3 | The real list is imported on the maintainer's phone and matches the source note | Import tests on invented data plus a maintainer spot check on device |
| 4 | Data safety items for v0 in decision 0014 work, and a restore drill passes | Round-trip test plus one restore on device |
| 5 | Accessibility items for v0 in decision 0015 pass their audits | Audit UI tests plus one VoiceOver pass on device |
| 6 | Diagnostics items for v0 in decision 0016 work, and an export opens on the phone | Maintainer run on device |
| 7 | Every required CI check passes on `main`; warnings are errors; `WishfullyCore` line coverage stays at or above 95% | CI |
| 8 | The app contains Apple frameworks and repository code exclusively | Forbidden APIs check plus the release bill-of-materials check |
| 9 | Paperwork items for v0 in [`paperwork/`](paperwork/README.md) are complete | Maintainer |
| 10 | Release notes and the dev-blog post for 0.0.1 are merged | Pull request review |
